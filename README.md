# Planner Room

Самостоятельное PWA-приложение. Загрузите **содержимое архива** в корень нового репозитория GitHub (не в подпапку `room`).

GitHub → Settings → Pages → Deploy from a branch → main → /(root) → Save.

Адрес: `https://USERNAME.github.io/REPOSITORY/`.

Для переноса данных: в прежнем Planner экспортируйте полный JSON; в Planner Room используйте Import a plan и выберите файл. Перед импортом экспортируйте резервную копию из Planner Room.

Приложение по умолчанию использует `progress-room.json` для GitHub-синхронизации. Синхронизация требует отдельной настройки GitHub и разрешений на запись в этот репозиторий. Не копируйте токены в файлы репозитория.

Проверено: относительные пути manifest, service worker и ассетов рассчитаны на корень отдельного репозитория.
